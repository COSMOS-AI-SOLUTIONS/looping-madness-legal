# Looping Madness Party – legal pages

Public web versions of the game's legal documents (privacy policy, Game Rules, user-generated content rules,
voice recording permissions, credits & open-source licenses, contact), served by GitHub Pages:
https://cosmos-ai-solutions.github.io/looping-madness-legal/

Do not edit these files by hand. They are generated in the game repository from `legal/*.md` +
`legal/legal_config.cfg` by `tools/build_legal_pages.gd` (output `build/legal_site/`) and copied here.
